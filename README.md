# jnhnbn01.github.io

Personal academic website of Hyeonbeen Jeon, served with GitHub Pages.

- `index.html` – page content (semantic sections: News, Education, Experience, Awards)
- `stylesheet.css` – all styles; colors are CSS variables at the top, with light/dark themes
- `images/` – profile photo, affiliation logos, favicons

Originally based on [Jon Barron's website](https://jonbarron.info/).
